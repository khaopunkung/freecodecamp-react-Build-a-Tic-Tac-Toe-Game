# React Tic-Tac-Toe Game (freeCodeCamp Lab)

โปรเจคเกม Tic-Tac-Toe (XO) สร้างขึ้นด้วย React เพื่อผ่านโจทย์ข้อกำหนดในหลักสูตร Front-End Development Libraries Certification ของ freeCodeCamp

## Tech Stack
- React (JSX)
- CSS3
- HTML5 (Babel Standalone)

## User Stories / Features
- สร้างคอมโพเนนต์ Board พร้อมปุ่มตารางขนาด 3x3 (คลาส `square`)
- สลับการแสดงผลระหว่าง X และ O ทุกครั้งที่คลิกช่องว่าง
- ระบบตรวจสอบผู้ชนะและหยุดการทำงานเมื่อเกมจบลงหรือมีผู้ชนะแล้ว
- ปุ่ม Reset Game (`button#reset`) สำหรับล้างค่าและเริ่มเกมใหม่
- แสดงข้อความบอกสถานะผู้ชนะ (Winner: X / Winner: O) หรือผลเสมอ (Draw)
